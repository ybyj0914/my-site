# 第一节 概述
## 一、项目规划的含义
### （一）产业发展规划

1.**定义**

对国家 / 地区某产业未来发展的预见设想；结合行业、地区实际，研判产业内外形势，分析业现存问题、产业体系、结构、产业链、经济社会环境影响；制定周期内产业定位、发展标、空间布局、实施方案。

2.**分类**

产业部门发展规划（行业发展规划）；产业空间发展规划

### （二）企业发展规划

1.**定义**

落实企业发展战略，结合自身资源、外部环境，谋划一定时期发展方向与目标，制定配套**行动方案**

作用：影响企业经营与发展前景；作为企业经营、项目决策的重要依据。

定位：**介于企业战略规划与企业计划二者之间的中间环节**。

| 类别     | 核心侧重                            | 内容特点           | 举例（光伏企业）                  |
| ------ | ------------------------------- | -------------- | ------------------------- |
| 企业战略规划 | 长远、总体、宏观；愿景、使命、长远目标、核心业务定位，纲领灵魂 | 方向性，不落地具体项目    | 发展成为国内光伏产业前十强             |
| 企业发展规划 | 一段时期内**具体方向、目标、实施方案，包含具体投资项目**  | 衔接战略，落到项目、产业链  | 5 年内建成 10 家标准化工厂，统一技术规模指标 |
| 企业计划   | 经营层面，事务性工作；细化实施步骤，落地执行          | 日常经营、年度任务，具体执行 | 年度落实投资，推进工厂建设             |
### （三）园区发展规划

1.园区定义

由**政府或企业**为实现产业发展目标设立的**特殊区位环境**；是区域经济、产业落地的重要空间载体，为项目落地提供建设场地。

 2.园区发展规划定义

结合区域产业、经济现状及发展态势，在划定区域内：明确**园区功能定位、空间布局**，规划**具体项目、产业链**，统筹土地、水电、交通、环境等资源要素配置，制定周期内发展目标与实施方案。

定位：**园区发展规划 = 指导园区中长期健康发展的行动纲领**；园区建设必须坚持**规划先行**
## 二、项目规划的任务  

| 规划类型       | 核心层级      | 核心任务                                        | 核心特点                           |
| ---------- | --------- | ------------------------------------------- | ------------------------------ |
| **产业发展规划** | 国家 / 区域宏观 | 培育符合政策、资源优势的产业体系；优化产业结构、升级技术、打造产业集群         | **只定产业、不落地项目**<br>宏观调控、无具体建设落地 |
| **企业发展规划** | 企业微观      | 落实企业战略；明确业务结构、投资方向、重点项目；配置资源、制定实施方案         | **企业自己的事**<br>包含具体投资项目，服务企业决策  |
| **园区发展规划** | 片区空间综合    | 确定园区定位、产业结构、空间布局、土地、基建、环保、安全、管理；明确重点项目与配套布局 | **既定产业、又落地建设**                 |

##  三、项目规划的特点

| 规划类型       | 特点                                                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **产业发展规划** | ①**导向性**：统筹产业方向、布局、结构调整，为宏观规划、产业政策提供依据<br>②**相关性**：立足地方资源、经济基础，匹配本地产业与资源承载力<br>③**约束性**：是项目决策基础前提，设置准入条件或负面清单<br>④**时效性**：随形势政策滚动调整、修编 |
| **企业发展规划** | ①**前瞻性**<br>②**针对性**：剖析企业现状、优势、问题，挖掘核心竞争力<br>③**认同性**：需要企业内部上下达成一致认同<br>④**时效性**：动态修正更新，打造竞争优势<br>⑤**可操作性**                            |
| **园区发展规划** | 具备**政府、企业双重属性**                                                                                                                        |

| **园区发展规划**         | ①服务招商引资<br>②落实资源条件<br>③促进园区基础设施建设<br>④<font color="#ff0000">作为规划环评的基础</font><br>⑤优化地方产业结构                          |

| 规划类型       | 编制原则                                                                                                                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **产业发展规划** | ①前瞻性：预判产业趋势，提出方向建议<br>②合规性：符合产业政策、上位规划<br>③产业关联原则<br>④可操作性原则<br>⑤可持续原则                                                                                                                     |
| **企业发展规划** | ①合规性：贴合国家行业政策，争取政策支持<br>②差异化：挖掘独有、难以模仿的核心能力<br>③价值递增：整合价值链，投入产出优化，价值增值最大化<br>④取舍原则：淘汰落后产能，不盲目追热点，减少投资失误<br>⑤创新原则：应对市场竞争<br>⑥可持续原则：近中期为主，兼顾长远<br>⑦低碳发展原则：落实双碳战略，构建低碳产业体系                    |
| **园区发展规划** | ①绿色发展原则<br>②集约发展原则：节约集约用地，严格执行投资强度、容积率、建筑系数等用地控制指标<br>③循环发展原则<br>④<font color="#ff0000">弹性发展原则</font>：整体规划、分步实施、重点开发 //分期<br>⑤针对性原则：因地制宜，突出自身特色定位与发展优势<br>⑥协同发展原则：围绕主导产业，大中小企业协作配套、错位、互补发展 |

# 第二节 产业发展规划报告的编制
## 一、产业发展规划报告编制要求
🔵 了解
1. 满足新形势新理念新要求。
2. 满足统筹协调资源利用要求。
3. 满足理顺健全管理机制要求。

## 二、产业发展规划报告重点内容

四大模块：**产业现状分析 → 产业发展定位和目标 → 规划实施方案 → 机制保障措施**

### （一）产业现状分析
| 分析模块        | 核心内容                                                                                                      |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| **外部环境分析**  | ①宏观环境：政治、法律、经济、社会、自然环境，重点研究重大行业政策<br>②行业环境：产业、市场、技术环境<br>③竞争环境：立足区域差异，挖掘<font color="#ff0000">比较优势</font> |
| **内部资源分析**  | 规划主体自身基础条件调研：<br><br>①产业现状调研<br>②生产力要素逐项分析<br>③资源型产业做资源条件分析<br>④环境、生态、能源、双碳等条件调研                          |
| **产业政策分析**  | 国家宏观政策、行业发展政策、行业规范条件、行业标准规范                                                                               |
| **SWOT 分析** | 汇总内外部分析结果，梳理：优势（S）、劣势（W）、机会（O）、挑战（T）                                                                      |
### （二）产业发展定位

规划**核心、纲领性内容**，凝练为指导思想、规划原则、规划目标

1. 指导思想：宏观总括，规划理念与原则的高度概括。
2. 规划原则：规划更具体和细化要求。
3. 规划目标：规划成果的高度概括和呈现，含形象目标 + 量化目标，分为总体目标、具体目标

- **总体目标**：产业规模、产能、产值、工业增加值、投资等。
- **具体目标**：细分产业产能产量；资源能源、环保、科创等指标。

### （三）规划实施方案

实施方案是规划的重点内容

包含：产业框架结构、发展思路、产业布局、备选项目、外部条件需求、建设时序；开展规划效果分析。

规划效果预估五大类指标（分预期性、约束性）

1. 经济指标：固投、销售收入、工业增加值、利税、利润率
2. 资源利用指标：能耗、水耗（单位销售收入 / 单位工业增加值口径）
3. 环保安全指标：污染物排放强度、废水废气达标率、危废处置、安全生产合格率
4. 创新发展指标：研发投入占比、高新技术产值占比
5. 社会效益指标：就业率等

### （四）产业发展机制保障措施
🔵 了解：提出规划实施所必需的机制保障措施，以提高规划的可操作性

## 三、产业发展规划的理论和方法

### （一）常用分析方法
ps：实务深入讲解

| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |

### （二）重点模型

| 分析方法               | 核心内容                                 | 主要用途                                |
| ------------------ | ------------------------------------ | ----------------------------------- |
| **产业生命周期**         | 四阶段：开发期 → 成长期 → 成熟期 → 衰退期            | 外部环境分析；判断产业所处阶段，决策进入 / 维持 / 扩张 / 退出 |
| **波特五力模型（行业结构分析）** | 五力：潜在进入者、替代品、购买者、供应者、现有竞争者抗衡         | 分析产业结构框架、竞争强度、产业利润率                 |
| **市场结构分析**         | 四类（竞争程度递减）：完全竞争 → 垄断竞争 → 寡头垄断 → 完全垄断 | 判断市场发展程度和影响因素                       |
| **需求弹性法**          | 两个分析角度：市场需求绝对因素、需求价格弹性               | 市场需求分析，判断市场成长性                      |
# 第三节 企业发展规划报告的编制★

## 一、编制要求

1. 落实企业发展战略
2. 统一企业发展共识
3. 统筹协调资源利用
4. 理顺企业管理机制

## <font color="#c00000">二、企业发展规划报告的重点内容</font>

企业发展规划报告编制重点是做好规划分析、规划定位、规划实施方案三个方面工作。  
**规划分析是基础，规划定位是核心，规划实施方案是重点**

### （一）规划分析

**1.企业现状调查与分析**

- 调查内容：发展历程、业务结构、经营、财务、资源占有
- 分析重点：经营结构、现存问题、面临挑战

**2.企业发展环境分析**（<font color="#ff0000">每年必考</font>）

|层级|分析内容|核心考点|
|---|---|---|
|**宏观**|PEST 分析（政治、经济、社会、技术）|研判宏观大势、外部大环境|
|**中观**|行业、市场、产品生命周期、行业供需、行业走势|行业层面判断|
|**微观**|竞争格局、参与者关系、客户需求、企业市场生存能力|企业贴身经营环境|

**市场分析和预测 = 外部环境分析最重要内容**

### （二）规划定位

规划定位是企业发展规划的<font color="#ff0000">核心和纲领性</font>内容，是体现规划高度和可操作性的最重要环节，应力求准确表达

由三部分组成：**指导思想 + 规划原则 + 发展目标**

| 定位模块 | 核心内涵               | 具体内容 / 分类                                                                               | 核心作用                   |
| ---- | ------------------ | --------------------------------------------------------------------------------------- | ---------------------- |
| 指导思想 | 宏观总括，统领全局          | 发展方向、思路、模式、市场地位、总体任务                                                                    | 起**引领和引导**作用           |
| 规划原则 | 承接指导思想，提出更加具体细化的要求 | 市场导向、产业延伸、循环经济、绿色低碳、智能融合                                                                | **约束企业资源分配**（资金、技术、人力） |
| 发展目标 | 量化落实企业战略，明确规划期发展水平 | 总体目标：企业规模、业务总量、市场份额、技术、人力、<font color="#ff0000">环保</font>、财务<br><br>分解目标：各业务单元、各管理部门子目标 | 把战略转化为可衡量的发展指标         |

 ⭐ **设定目标五大原则**

总量增速适配自身能力 / 利润指标客观实际 / 目标结构合理 / 增量估算准确 / 兼顾存量变化

### （三）规划实施方案

1. **明确业务结构（麦肯锡三层面理论）**

| 业务类型     | 市场定位          | 核心特点           | 企业策略                |
| -------- | ------------- | -------------- | ------------------- |
| **基础业务** | 企业当前支柱、利润主体   | 市场成熟、优势稳定、造血主力 | 适度投入，**稳现金流、保基本盘**  |
| **战略业务** | 当前重点发展，未来核心支柱 | 成长性高、前景好、潜力大   | **加大投入**，重点培育，打造新主力 |
| **新兴业务** | 未来储备赛道        | 处于探索孵化阶段、机会型业务 | 挖掘孵化，布局未来新增长点       |

2. **企业四种发展模式（高频考点）**

| 发展模式             | 核心内涵              | 典型行为                                                    |
| ---------------- | ----------------- | ------------------------------------------------------- |
| **集中核心业务**       | 剥离非主营业务，资源全部聚焦主业  | 砍掉副业、回笼资金、强化核心竞争力                                       |
| **纵向一体化（全链条延伸）** | 沿产业链上下游延伸，增加价值链环节 | **后向一体化**：向上游原材料、配套生产延伸；<br>**前向一体化**：向下游深加工、终端销售、用户端延伸 |
| **横向一体化**        | 同行业、同生产环节规模扩张     | 并购、兼并、重组、合资、特许经营、分包联营                                   |
| **多元化发展**        | 跨行业、跨领域拓展新业务      | 脱离原有产业链，布局全新赛道                                          |

3. 明确重点任务（<font color="#0070c0">了解</font>）
4. 制定规划实施计划（<font color="#0070c0">了解</font>）
5. 提出保障和支撑体系建设（<font color="#0070c0">了解</font>）
6. 预测规划效果（<font color="#0070c0">了解</font>）

## <font color="#c00000">三、企业发展规划的分析方法</font>
### （一）企业对标分析
概念：是将本企业各环节经营状况与竞争对手或行业内外一流企业进行对照分析，研究本企业水平
及存在差距的过程。

| 步骤                                     | 核心考点                                                           |
| -------------------------------------- | -------------------------------------------------------------- |
| 1. 确定对标内容                              | 优选**关键经营、盈利环节**（业务结构、质量、技术、经营、财务），指标量化、统一口径，**不面面俱到**          |
| <font color="#c00000">2. 选择对标企业</font> | 四类标杆：<br>①竞争对手（首选）<br>②行业领先企业（首选、定赶超目标）<br>③跨行业技术标杆<br>④客户需求标杆 |
| 3. 收集对标数据                              | 保证范围、口径、定义一致，数据合法、可比                                           |

# 第五节 规划环境影响评价

## 一、规划环境影响评价的目的和原则

### （一）规划环评的目的

以**改善环境质量、保障生态安全**为目标；

1. 论证规划方案生态环境合理性、环境效益，给出规划优化调整建议；
2. 提出不良环境影响减缓措施、环保管控要求；
3. 为规划决策以及实施阶段生态环境管理提供依据。

### （二）评价原则

1. 早期介入、过程互动
2. 统筹衔接、分类指导
3. 客观评价、结论科学

## 二、规划环境影响评价的适用范围和责任主体

### （一）适用范围（《环境影响评价法》2018 修正）

1. **专项规划（非指导性）**：规划草案上报审批前，编制**环境影响报告书**，报送审批机关。
2. **专项规划中的指导性规划**（以发展战略为主要内容）：编写**环境影响的篇章或者说明**。

环评具体范围：国务院生态环境主管部门会同有关部门划定，报国务院批准。

### （二）责任主体

1. **评价编制**

规划编制机关自行编制，或委托技术机构编制；**规划编制机关对环评文件质量负责**。

2. **审查报送**

- 综合性规划、专项规划指导性规划：<font color="#ff0000">环评篇章 / 说明作为规划草案组成部分</font>一并报送；缺少则要求补充，拒不补充不予审批。
- 设区的市级以上政府审批的专项规划：审批前生态环境主管部门组建审查小组审查环境影响报告书，出具书面审查意见。
- 审查专家：从专家库**随机抽取**；参与报告书编制的专家，不得参加该项目审查小组。

3. **跟踪评价**

对环境有**重大影响**的规划实施后，**规划编制机关组织跟踪评价**；结果上报审批机关，通报生态环境主管部门。

## 五、项目用地预审

依据：自然资源部令第 68 号，可行性研究报告审批、项目申请书核准的**前置**必备文件。

### （一）申请受理

|项目类型|提出预审申请阶段|
|---|---|
|审批类项目|可行性研究阶段|
|核准类项目|项目申请书核准之前|
|备案类项目|完成备案手续之后|

提交材料：

1. 用地<font color="#ff0000">预审申请表</font>
2. 用地<font color="#ff0000">预审申请报告</font>（项目概况、占地、规划符合性、用地标准、供地政策）

1. 符合土地利用总体规划
2. 一般项目不得占用基本农田
3. 节约集约利用土地
4. 符合国家供地政策

### （三）用地预审审查主要内容

1. 是否符合土地利用总体规划、年度计划、建设用地标准
2. 重大项目确难避让永久基本农田：可研阶段论证占用必要性、合理性、补划方案，报自然资源部预审，农用地转用征收报国务院审批
3. 国家重大项目确需占用生态保护红线，按规定办理用地审批
4. 申报材料包含**节约集约用地论证分析专章**

分级预审、**同级审查**；审批 / 核准 / 备案在哪一级，同级自然资源主管部门负责预审。

### （五）预审有效性

- 有效期：**3 年，自批准之日起算**
- 土地用途、选址发生重大调整，**应当重新申请预审**
- 未预审或预审不通过：不得批复可研、不得核准项目申请书；不得办理农用地转用、土地征收、供地手续。
