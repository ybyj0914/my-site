# 第一节 概述

## 一、项目申请书的含义和作用

项目申请书：是企业投资建设政府<font color="#ff0000">核准</font>项目时，为获得项目核准机关对拟建项目的行政许可，按核准要求报送的项目论证报告。政府不再履行项目建议书、可行性研究报告和开工报告的程序。

- 《企业投资项目核准和备案管理条例》要求，对关系国家安全、涉及全国重大生产力布局、战略性资源开发和重大公共利益等项目，实行核准管理。

- 核准机关：应当从是否危害经济安全、社会安全、生态安全等国家安全，是否符合相关发展建设规划、技术标准和产业政策，是否合理开发并有效利用资源，是否对重大公共利益产生不利影响等方面对项目进行审查。

- 申请书作用：从政府公共管理的角度，回答项目建设的<font color="#ff0000">外部性、公共性</font>事项，包括维护经济安全、合理开发利用资源、保护生态环境、优化重大布局、保障公众利益、防止出现垄断等，为核准机关对项目进行核准提供依据。

## 二、项目申请书的类别

三类：企业投资项目申请书、外商投资项目申请书、境外投资项目申请书。

### （一）企业投资项目申请书

 ✅ 正文包含 4 项内容

1. 项目单位情况
2. 拟建项目情况
3. <font color="#ff0000">资源</font>利用和<font color="#ff0000">生态</font>环境影响分析
4. <font color="#ff0000">经济</font>和<font color="#ff0000">社会</font>影响分析

 ✅ 应当附具的文件

1. 选址意见书：**仅限划拨国有土地**项目（出让土地不需要）
2. 用地（用海）预审意见：自然资源部门明确豁免预审的除外
3. 法律、行政法规规定的其他相关手续

### （二）外商投资项目申请书

#### 1.适用范围

依据：<u>《外商投资项目核准和备案管理办法》（国家发改委令 2014 年第 12 号）</u>。拟申请<font color="#ff0000">核准</font>的各类外商投资项目，均按国家要求编制外商投资项目申请书。

适用项目类型：中外合资、中外合作、外商独资、外商购并境内企业、外商投资企业增资及再投资等。

#### 2.正文内容

1. 项目及投资方情况
2. 资源利用和生态环境影响分析
3. 经济和社会影响分析

⚠️ 对比企业投资申请书的 4 项：外商投资少了单独的 "拟建项目情况"，并入了第 1 项 "项目及投资方情况"。

📌 **特殊情形：外国投资者并购境内企业项目，还应增加**

- 并购方情况
- 并购安排
- 融资方案
- 被并购方情况
- 被并购后经营方式、范围和股权结构
- 所得收入的使用安排

#### 3.应附文件

| 序号  | 附件内容                                                          | 备注                                |
| :-: | ------------------------------------------------------------- | --------------------------------- |
|  ①  | 中外投资各方的企业注册证明材料；经审计的最新财务报表（**资产负债表、利润表、现金流量表**）；开户银行出具的资金信用证明 | 财务报表三表                            |
|  ②  | 投资意向书；**增资、并购项目的公司董事会决议**                                     | 仅增资 / 并购需董事会决议                    |
|  ③  | 选址意见书                                                         | **仅以划拨方式提供国有土地使用权的项目**            |
|  ④  | 用地预审意见                                                        | **不涉及新增用地、在已批准建设用地范围内改扩建的项目，可豁免** |
|  ⑤  | 环境影响评价审批文件                                                    | **需要时**才附                         |
|  ⑥  | 节能审查意见                                                        | **需要时**才附                         |
|  ⑦  | 以国有资产出资的，需主管部门出具确认文件                                          | 仅国有资产出资情形                         |
|  ⑧  | 法律法规规定应提交的其他文件                                                | 兜底条款                              |

#### 4.其他
1. 外商投资项目范围：执行《外商投资产业指导目录》中的“鼓励外商投资产业目录”、《外商投资准入特别管理措施（负面清单）》和《自由贸易试验区外商投资准入特别管理措施（负面清单）》。

2. 外商投资项目核准权限：执行《政府核准的投资项目目录》。《外商投资产业指导目录》中总投资（含增资）<font color="#ff0000">3 亿</font>美元及以上限制类项目，由国务院投资主管部门核准，其中总投资（含增资）<font color="#ff0000">20</font> 亿美元及以上项目报国务院备案；总投资（含增资）3 亿美元以下限制类项目，由省级政府核准。

### （三）境外投资项目申请书

#### 1.境外投资的定义

**境外投资**：境内企业直接或通过其控制的境外企业，以投入资产、权益或提供融资、担保等方式，获得境外所有权、控制权、经营管理权及其他相关权益的投资活动。

#### 2.核准管理范围

**核准范围 = 敏感类项目**。非敏感类项目实行**备案**管理，不在申请书范围内。

敏感类项目 = 敏感国家和地区 + 敏感行业

（1）敏感国家和地区（4 类）
1. 与我国**未建交**的国家和地区；
2.  **发生战争、内乱**的国家和地区；
3. 根据我国缔结或参加的国际条约、协定等，**需要限制企业对其投资**的国家和地区；
4. 其他敏感国家和地区。

（2）敏感行业（4 类， 敏感行业目录由**国家发展改革委**发布。）

1. **武器装备**的研制、生产、维修；
2. **跨境水资源**开发利用；
3. **新闻传媒**；
4. 根据我国法律法规和有关调控政策，需要限制企业境外投资的行业。

#### 3. 核准机关与提交方式

- **核准机关**：**国家发展改革委**（唯一核准机关，无省级）
- **提交渠道**：通过**网络系统**提交项目申请书及附件
- **提交主体**：**中央管理企业** → 由其**集团公司或总公司**向核准机关提交；**地方企业** → **直接**向核准机关提交。

#### 4. 申请书内容（4 项）

1. **投资主体情况**；
2. **项目情况**：包括项目名称、投资目的地、主要内容和规模、中方投资额等；
3. **项目对我国国家利益和国家安全的影响分析**；
4. **投资主体关于项目真实性的声明**。

 📌 境外投资申请书的独有亮点：第 3 项 "国家利益和国家安全影响分析" + 第 4 项 "真实性声明"，是另外两类申请书没有的。

# 第二节 项目申请书的编制

## 一、项目申请书的编制依据

1. 有关法律、法规、政策文件等；
2. 项目申请书编制的前置审批事项：
   - 规划选址意见书（**仅指以划拨方式提供国有土地使用权的项目**）；
   - 用地（用海）预审（**自然资源主管部门明确可以不进行用地预审的情形除外**）；
   - 对**重特大项目**，环评（海洋环评）审批也作为前置条件；
3. 项目可行性研究报告、专项报告以及相应的评估或审查意见；
4. 核准招标内容的企业投资项目，还应附有关招标内容；
5. 投标、并购或合资合作项目的特殊要求。

📌 之前已存在的东西，都可以作为编制依据
## 二、项目申请书的编制原则

依据《政府核准和备案投资项目管理条例》《企业投资项目核准和备案管理办法》和《企业境外投资管理办法》等要求：

- 由**项目单位**或者其**委托的工程咨询单位**按照项目申请书**通用文本**和**行业示范文本**编写；
- 编制应做到<font color="#ff0000">依法、独立、客观、公正</font>，编制单位应对其编制的内容负责；
- 重点从<font color="#ff0000">规划布局、资源利用、征地移民、生态环境、经济和社会影响</font>等方面进行论述；
- **不必**详细分析和论证项目<font color="#ff0000">市场前景、经济效益、资金来源、产品技术方案</font>等由企业自主决策的内容；
- 内容和深度应满足评估机构进行项目**评估**和有关核准部门进行**核准**的要求。

⚠️ 易混点：申请报告论证"外部性"（公共角度），不论证"企业风险""盈利性"（企业自主决策内容）。

## 三、项目申请书的编制内容与要求

### （一）项目单位及拟建项目情况（抄可研）

#### 1.项目单位情况

项目申报单位的基本情况：主营业务、营业期限、资产负债、企业投资人（或者股东）构成、主要投资项目、现有生产能力、项目单位近几年信用情况等。

⚠️ 易错点：是"信用情况"，不是"盈利情况"。

#### 2.拟建项目情况

| 序号  | 项目               | 内容                                                                                                                              |
| :-: | ---------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| （1） | **拟建项目概况**       | 建设背景、建设地点、主要建设内容、建设（开发）规模与产品方案、工程技术方案、主要设备选型、配套公用辅助工程、投资规模和资金筹措方案等。                                                             |
| （2） | **规划符合性**        | 阐述国民经济和社会发展总体规划、主体功能区规划、区域规划、城镇体系规划、城市或镇总体规划、行业发展规划等各类规划与拟建项目密切相关的内容。遵循 "具体项目建设方案服从相关规划要求、下级规划服从上级规划、专项规划和区域规划服从本级和上级总体规划" 的原则。 |
| （3） | **产业政策符合性**      | 对照有关法律法规、产业政策规定，阐述与拟建项目相关的产业结构调整、产业发展方向、产业空间布局、行业规范条件、产业技术政策等内容。                                                                |
| （4） | **技术标准和行业准入符合性** | 阐述与拟建项目相关的技术标准、行业准入政策、准入标准等内容，为项目准入分析提供依据。                                                                                      |
| （5） | **前置性要件**        | 阐述拟建项目取得规划选址、土地利用等前置性要件的情况。                                                                                                     |

### （二）资源开发及综合利用分析（略看，顶多 2 分）

对于**开发**和**利用**重要资源的企业投资项目，要从建设节约型社会、发展循环经济等角度，对资源开发、利用的合理性和有效性进行分析论证。

#### 1.资源开发方案

- 资源开发类项目：金属矿、煤矿、石油天然气矿、建材矿以及水（力）、森林等资源的开发，应分析拟开发资源的<font color="#ff0000">可开发量、自然品质、赋存条件、开发价值</font>，评价是否符合资源综合利用要求。
- 分析评价中应：重视对资源开发的**规模效益和使用效率**分析，限制盲目开发，避免浪费；分析拟采用的**开采设备和技术方案**是否符合提高资源开发利用效率的要求；评价资源开发方案是否符合**改善资源环境及促进相关产业发展**的政策要求。
- 资源承载力：某区域资源对人口增长和经济发展的支持能力，主要包括可供开发利用的自然资源数量、环境对生产和生活过程所产生的各种废弃物的最大负荷量。
- 资源条件：项目位置和境界、勘探程度与资源储量、自然品质与赋存条件。
- 开采方案（4 项）：<font color="#ff0000">开采规模、开拓与开采方案、主要设备选型、洗选加工与产品方案</font>。
- 资源开采类项目还应进行**地表沉陷治理分析**。

#### 2.资源利用方案

- 包括项目需要占用的重要资源品种、数量及来源情况；
- 多金属、多用途化学元素共生矿、伴生矿、尾矿以及油气混合矿等的<font color="#ff0000">资源综合利用方案</font>；
- 通过对单位生产能力主要资源消耗量指标的对比分析，评价资源利用效率的先进程度；
- 分析评价项目建设是否会对地表（下）水等其他资源造成不利影响；
- 涉及矿产资源开发的项目，应分析**采矿回采率、选矿回收率**等指标，并与国家标准、行业平均水平、国内外先进水平对比；
- 涉及资源加工类项目（钢铁、有色金属、燃煤电厂、石化、林产品加工、林纸一体化等），从可持续角度出发，遵循建设资源节约型社会和发展循环经济的原则；
- 用水较多、涉及重大水资源开发的项目，重点分析所在地水资源状况，提出详细的项目用水方案；
- 资源消耗指标：一般而言应达到国内外同行业或地区先进水平，<font color="#ff0000">力争达到国际水平</font>。

#### 3.资源节约措施

- 阐述项目方案中作为原材料的各类金属矿、非金属矿及水资源**节约的主要措施**方案；
- 耗水量大或严重依赖水资源、涉及主要金属矿非金属矿开发利用的项目，应对节水措施及原材料节约方案进行**专题论证**；
- 占用稀缺性资源，或者资源承载能力较低的项目建设方案，应尽可能寻找**替代方案**。

### （三）生态环境影响分析（略看，顶多 2 分）

应通过生态和环境影响分析，明确项目建设是否涉及<font color="#ff0000">生态保护红线</font>以及与相关<font color="#ff0000">规划环评</font>结论的相符性。

#### 1.生态和环境现状

#### 2.生态环境影响分析

- 生态影响分为<font color="#ff0000">污染影响和非污染影响</font>，其影响分析主要包括 7 项：
  1. 自然环境及社会经济概况；
  2. 植被及其物种多样性的影响；
  3. 主要植被类型及其种类组成；
  4. 植被区系成分分析；
  5. 主要资源植物状况；
  6. 项目建设后植被的恢复预测；
  7. 主要生态系统类型及其特点等。
- 可能产生水土流失影响的项目（如大型水利设施、高速铁路或公路等）：应重点结合<font color="#ff0000">旱坡耕地垦殖率、森林覆盖率、人口密度</font>等进行水土流失影响分析。
- 分析项目建设可能对<font color="#ff0000">历史文化遗产、自然遗产、风景名胜和自然景观</font>等特殊环境产生的影响及影响程度。
- 对于"两高"项目（高耗能、高排放）：应分析其<font color="#ff0000">碳排放情况</font>，并与项目所在行业或所在区域具体要求进行对比分析。

#### 3.生态环境保护措施

- 从减少污染排放、防止水土流失、强化污染治理、促进清洁生产、保持生态环境可持续能力的角度提出保护措施；
- 治理措施方案应反映不同污染源和污染排放物的性质特点，采用的技术和设备满足先进性、适用性、可靠性要求；符合发展循环经济要求，对废气、废水、固体废弃物提出回收处理和再利用方案；
- 污染治理效果应能满足<font color="#ff0000">达标排放</font>要求；环境影响的监测、控制方案满足环境管理要求；
- 对历史文化遗产、自然遗产、自然保护区、森林公园、重要湿地、风景名胜和自然景观等可能造成不利影响的建设项目，应提出保护措施方案；
- 生态环境保护措施应通过<font color="#ff0000">技术经济比选</font>提出推荐方案，包括：<font color="#ff0000">技术水平对比、治理效果对比、管理及监测方式对比、环境效益对比</font>；
- "两高"项目：应分析其<font color="#ff0000">碳减排措施和碳减排潜力</font>，提出双碳有关要求和相应措施。

### （四）经济影响分析（重点★）

**定义**：经济影响分析，是对投资项目所耗费的社会资源及其产生的经济效果进行论证，分析项目对行业发展、区域和宏观经济的影响，从而判断拟建项目的经济合理性。

#### 1.社会经济费用效益或费用效果分析

- 适用情形：产出物不具备实物形态且明显涉及公众利益的<font color="#ff0000">无形产品项目</font>（水利水电、交通运输、市政建设、医疗卫生等公共基础设施项目）；具有明显外部性影响的<font color="#ff0000">有形产品项目</font>（如污染严重的工业产品项目）。
- 分析方法：

| 产出效果情况            | 处理方式         | 具体指标 / 方法                              |
| ----------------- | ------------ | -------------------------------------- |
| 经济费用和效益**能够货币量化** | 编制经济费用效益流量表  | 计算**经济净现值（ENPV）**、**经济内部收益率（EIRR）**等指标 |
| 产出效果**难以货币量化**    | 尽可能采用非货币量纲量化 | 采用**费用效果分析**                           |
| **难以量化**分析        | 进行定性分析描述     | ——                                     |

⚠️ 易错点：难以货币量化的项目用"费用效果分析"，不是"费用效益分析"。

#### 2.行业影响分析

- 适用情形：在行业内具有重要地位、影响行业未来发展的重大投资项目。
- 内容：<font color="#ff0000">产业结构调整</font>、<font color="#ff0000">行业技术进步</font>、<font color="#ff0000">行业竞争格局</font>；特别要对是否可能形成<font color="#ff0000">行业垄断</font>进行分析评价。
- 对产能过剩行业应注重<font color="#ff0000">宏观总量分析</font>影响，避免资源浪费和加剧生态环境恶化；评价是否符合重大生产力布局。

#### 3.区域经济影响分析

- 适用情形：对区域经济可能产生重大影响的项目。
- 角度：区域经济发展、产业空间布局、当地财政收支、社会收入分配、市场竞争结构、对当地产业支撑作用和贡献等。
- 包括对区域现有发展条件、经济结构、城镇建设、劳动就业、土地利用、生态、环境等方面现实和长远的影响。

#### 4.宏观经济影响分析

- 适用情形：投资**规模巨大**、对国民经济有重大影响的项目（基础设施、科技创新、战略性资源开发等）。
- 内容：国民经济总量增长、国家产业结构调整和升级、重大产业布局、劳动力就业结构变化、物价变化、收入分配、重要产业的国际竞争力以及区域之间协调发展的影响；国家承担项目建设的能力即<font color="#ff0000">国力分析</font>；项目时机选择对国民经济影响的分析等。

- 涉及<font color="#ff0000">国家经济安全</font>的项目，应分析拟建项目对经济安全的影响，提出维护经济安全的措施。经济安全分析内容
  1. <font color="#ff0000">产业技术安全</font>：关键技术是否受制于人、是否拥有自主知识产权、技术壁垒风险；
  2. <font color="#ff0000">资源供应安全</font>：重要资源来源、受国际市场供求格局和价格变化的影响、垄断格局与运输线路安全；
  3. <font color="#ff0000">资本控制安全</font>：股权控制结构、中方资本对关键产业的资本控制能力、外资不适当进入可能造成的垄断和不正当竞争；
  4. <font color="#ff0000">产业成长安全</font>：是否有利于推动国家相关产业成长、提升国际竞争力、规避产业成长风险；
  5. <font color="#ff0000">市场环境安全</font>：国外反倾销等贸易救济措施、知识产权保护、技术性贸易壁垒对相关产业的障碍。

### （五）社会影响分析（重点★，与第七章重复）

适用情形：因征地拆迁等可能产生重要社会影响的项目；扶贫、区域综合开发、文化教育、公共卫生等具有明显社会发展目标的项目。

#### 1.社会影响效果分析

阐述拟建项目的建设及运营活动对项目所在地可能产生的社会影响和社会效益，其中对<font color="#ff0000">就业效果</font>要进行重点分析。（利益相关者损益）

- 社会影响包括正面影响（通常称为<font color="#ff0000">社会效益</font>）和负面影响（通常称为<font color="#ff0000">社会风险</font>）。
- 影响内容：对居民收入、生活水平和质量、就业的影响、对不同利益群体、弱势群体利益的影响、对文化和教育以及卫生、当地基础设施和社会服务容量、少数民族风俗习惯和宗教的影响等。

- 社会影响效果分析应重点阐述 3 项：
  1. <font color="#ff0000">社会影响区域范围的界定</font>：应能涵盖所有潜在影响的社会因素，不受行政区划等因素的限制；
  2. <font color="#ff0000">区域内受项目影响的机构和人群的识别</font>：包括各类直接或间接受益群体，也包括可能受到潜在负面影响的群体；
  3. <font color="#ff0000">分析项目可能导致的各种社会影响效果</font>：包括直接影响效果和间接影响效果（增加就业、社会保障、劳动力培训、卫生保健、社区服务等），分析哪些是主要影响效果、哪些是次要影响效果。

#### 2.社会适应性分析

分析拟建项目能否为当地的社会环境、人文条件所接纳，评价项目与当地社会环境的相互适应性，提出改进性方案。

- 应确定项目的<font color="#ff0000">主要利益相关者</font>，分析利益相关者的需求，研究目标人群对项目建设内容的认可和接受程度，评价各利益相关者的重要性和影响力，阐述各利益相关者参与项目方案确定、实施管理和监测评价的措施方案。
- 利益相关者：与项目或发展规划有利害关系的人、群体或机构，包括<font color="#ff0000">主要利益相关者</font>（拟建项目的直接受益者或直接受到损害的人）和<font color="#ff0000">次要利益相关者</font>（与项目具体组织实施等相关的人员或机构，如金融机构、政府部门等）。

⚠️  效果分析：关注**利益相关者会受到什么影响**；适应性分析：关注**利益相关者对项目的态度、接纳程度、如何参与项目**。
#### 3.社会稳定风险分析

重点针对拟建项目直接关系人民群众切实利益且涉及面广、容易引发社会稳定问题的项目。

- 社会风险主要包括：<font color="#ff0000">宗教信仰、社会治安、文化素质、公众态度</font>等方面给项目建设和运营带来困难和损失的可能性。应重点识别各方面的<font color="#ff0000">社会风险持续时间和影响程度</font>。
- 程序：在<font color="#ff0000">风险调查、风险识别、风险估计、提出风险防范和化解措施、判断风险等级</font>基础上，从<font color="#ff0000">合法性、合理性、可行性和可控性</font>等方面进行分析。

#### 4.其他社会风险及对策分析

针对项目建设所涉及的其他社会因素进行社会风险分析，提出协调项目与当地社会关系、规避社会风险、促进项目顺利实施的措施方案。

### （六）境外投资者并购境内企业项目申请书

应重点包括以下内容：

1. **并购方情况**：近年投资人或企业基本情况、在中国大陆投资情况及拥有实际控制权的同行业企业产品或服务的市场占有率、公司业绩等；
2. **被并购方情况**：近年企业基本情况、生产经营现状、业务和产品结构、债权债务关系和资产评估情况等；
3. **并购方案**：并购理由、并购方式、股权结构及实际控制权变化、债权债务关系变化、融资安排、职工安排、资产处置等；
4. **并购后企业**的治理结构、经营方式、业务范围、产品结构，被并购方及其股东所得收入的使用安排；
5. 有关法律法规和规章要求的其他内容。

# 第三节 项目申请书的评估要点

- <font color="#ff0000">项目申请书评估报告</font>是项目核准机关进行核准的重要参考依据。
- 根据报送主体不同，核准评估分三类：<font color="#ff0000">企业投资项目、外商投资项目、境外投资项目</font>
- 按照"谁投资、谁决策、谁收益、谁承担风险"的原则，落实企业投资自主权，政府主要从维护经济安全、合理开发利用资源、保护生态环境、优化重大布局、保障公共利益、防止出现垄断等方面进行核准。
- 对于外商投资项目，政府还要从<font color="#ff0000">市场准入、资本项目管理</font>等方面进行核准。
- 项目申请书主要围绕<font color="#ff0000">"外部性"</font>进行评估，必要时再剖析"内部性"因素。

## 一、企业投资项目的项目申请书评估

评估内容共 10 项：

### （一）申报单位及项目概况评估

提出申报单位的申报资格以及是否具备承担拟建项目投资建设的基本条件的评估意见，并对项目概况进行阐述，为核准咨询评估相关章节编写提供项目背景基础。

### （二）发展规划、产业政策和行业准入评估

1. 发展规划评估：评估拟建项目是否符合各类规划要求，提出与有关规划内容的衔接性及目标的一致性等评估结论；
2. 产业政策评估：评估工程技术方案、产品方案等是否符合产业结构调整、产业空间布局、产品发展方向、产业技术创新等法律法规、产业政策要求；
3. 行业准入评估：评估拟建项目和项目建设单位是否符合有关行业准入标准的规定；
4. 自主创新和采用先进技术评估：评估是否符合增强自主创新能力、建设创新型国家的发展战略要求，是否符合国家科技发展规划要求；
5. 项目建设必要性评估：评估项目目标及功能定位是否合理，是否符合各类规划、法律法规、宏观调控政策、产业政策、行业准入标准、重大布局优化、自主创新和采用先进技术等要求。

### （三）资源开发及综合利用评估

资源开发方案评估；资源利用方案评估；资源节约措施评估。

### （四）节能方案评估

用能标准和节能规范评估；能耗状况和能耗指标分析；节能措施和节能效果分析。

### （五）建设用地、征地拆迁及移民安置评估

1. 项目选址及用地方案评估；
2. 土地利用合理性评估；
3. 征地拆迁和移民安置规划方案评估。

### （六）环境和生态影响评估

1. 环境和生态影响程度评估；
2. 生态环境保护措施评估；
3. 地质灾害影响评估；
4. 特殊环境影响评估；
5. 对于"两高"项目，应对其<font color="#ff0000">碳排放强度和总量</font>进行评估，并与项目所在行业或所在区域具体要求进行对比分析。

### （七）经济影响评估（重点）

1. 经济费用效益或费用效果分析的评估：从社会资源优化配置角度，评估经济费用、效益的识别计算是否恰当、分析方法是否恰当，以及拟建项目的经济合理性；
2. 行业影响评估：对行业发展可能产生的影响进行分析评估，对是否可能形成行业垄断进行分析；
3. 区域经济影响评估：从区域经济发展、产业空间布局、当地财政收支、社会收入分配、市场竞争结构等方面评估；
4. 宏观经济影响评估：从国民经济整体发展角度分析；涉及国家经济安全的重大项目，评估对国家<font color="#ff0000">产业技术安全、资源供应安全、资本控制安全、产业成长安全、市场环境安全</font>等方面的影响。

### （八）社会影响评估（重点）

1. 社会影响效果评估：评估拟建项目对就业、减轻贫困、社区发展等方面的影响，包括正面和负面影响效果；
2. 社会适应性评估：调查分析利益相关者需求、目标人群认可和接受程度，评估项目与当地社会环境的相互适应性；
3. 社会风险及对策措施评估：确认项目可能存在的负面社会影响，提出协调项目与当地社会关系、减轻负面影响的措施方案。

### （九）主要风险及应对措施评估

1. 主要风险综述：总结项目在维护经济安全、合理开发利用资源、保护生态环境、优化重大布局、保护公共利益、防止出现垄断等方面可能存在的主要风险；
2. 风险影响程度评估：对重要风险因素的性质特征、未来变化趋势及可能造成的影响后果进行分析评估；需进行经济费用效益分析的项目，还应通过<font color="#ff0000">敏感性分析或风险概率分析</font>进行定量分析评估；
3. 风险应对措施评估：对可能严重影响项目投资建设及运营效果的风险因素提出应对措施，并对措施方案的合理性及可行性提出咨询评估意见。

### （十）主要结论和建议

1. 主要评估结论：提出核准咨询评估的主要结论，并对拟建项目是否符合核准条件提出明确的评估意见；
2. 主要措施建议：对评估中发现的各种问题，提出解决的对策措施和建议。

## 二、外商投资项目的项目申请书评估

着重论证以下 6 项内容：

1. 是否符合国家法律法规、《外商投资产业指导目录》《外商投资准入特别管理措施（负面清单）》《自由贸易试验区外商投资准入特别管理措施（负面清单）》等有关规定；
2. 是否符合发展规划、产业政策及准入标准；
3. 是否合理开发并有效利用了资源；
4. 是否影响国家安全和生态安全；
5. 是否对公众利益产生重大不利影响；
6. 是否符合国家<font color="#ff0000">资本项目管理、外债管理</font>的有关规定。

## 三、境外投资项目的项目申请书评估

着重论证以下 5 项内容：

1. 是否符合国家法律法规和产业政策、境外投资政策；
2. 是否符合互利共赢、共同发展的原则；
3. 是否危害国家主权、安全和公共利益，是否违反我国缔结或参加的<font color="#ff0000">国际条约</font>；
4. 是否符合国家资本项目管理相关规定；
5. 投资主体是否具备相应的投资实力。
