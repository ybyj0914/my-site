# 第一节 投资项目决策概述
## 一、投资项目的定义和分类

| 分类依据  | 项目类型                             |
| ----- | -------------------------------- |
| 按实施主体 | 政府投资项目、企业投资项目、政府和社会资本合作（PPP）项目等  |
| 按建设性质 | 新建、改建、技术改造、扩建                    |
| 按融资主体 | 新设法人项目、既有法人项目、资本运作项目（兼并、重组、收购等）  |
| 按投资目的 | 公益性投资、基础性投资和竞争性投资，即非经营性、准经营性和经营性 |
| 其他分类  | 按行业领域/投资规模/所有制等                  |
## 二、投资项目目标  
🔴 **<font color="#ff0000">考点：区分项目目标，特别是具体目标</font>**

（一）宏观目标。项目建设对国家、地区、部门或行业要达到的整体发展目标所产生的积极影响和作用。

（二）具体目标。项目建设要达到的具体效果。包括效益目标和功能目标。

| <center>分类</center> | <center>说明</center>                      | <center>例子</center>                     |
| ------------------- | ---------------------------------------- | --------------------------------------- |
| 效益目标                | 项目实现的**经济、社会、环境、生态效益**的结果数值，是项目运行之后产出的效果 | 企业的投资收益；公共基础设施满足的需求、服务覆盖范围；环境治理项目的改善结果。 |
| 功能目标                | 项目本身的功能定位，是项目建成之后具备的硬件能力、设施条件            | 线路长度、车站数量、床位数量、灌溉面积、防洪标准、产能规模           |

（三）建设项目目标与宏观规划发展目标的一致性  
🔵 了解：套话  
项目目标应服从国家 / 地区 / 行业规划，符合：产业政策、区域 / 行业 / 城市规划、资源合理利用、高质量发展、环保安全、改善民生、可持续发展。 //小家服从大家

##  三、投资项目决策的含义和原则

### （一）决策的含义

 决策是指人们为了实现特定的目标，在掌握大量有关信息的基础上，运用科学的理论和方法，系统地分析主客观条件，提出若干备选方案，分析各种方案的优缺点，并从中选出较优方案的过程。

 决策过程可以分为**信息收集、方案构造设计、方案评价、方案抉择**四个阶段。【🟡高频】

分类：按决策对象分：投资决策、融资决策、营销决策；按决策目标的数量分：单目标决策、多目标决策；按决策问题面临条件分：确定型决策、风险型决策、不确定型决策

### （二）投资项目决策的类别

| 决策类别     | 核心目标/原则                                         |
| -------- | ----------------------------------------------- |
| 政府投资项目决策 | 实现经济调节、满足国家经济安全和社会公共需求、促进经济社会可持续发展              |
| 企业投资项目决策 | 以获得经济效益、社会效益和提升持续发展能力为目标，依法依规自主决策，同时按照有关规定备案或核准 |
| 金融机构贷款决策 | 独立审贷、自主决策、自担风险                                  |

### （三）**政府投资项目与企业投资项目决策的区别**
🔴 **<font color="#ff0000">考点</font>

| 对比维度    | 政府投资项目                                                                                   | 企业投资项目                                                                    |
| ------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 投资主体    | 政府投资管理部门                                                                                 | 企业或个人                                                                     |
| 决策人     | 投资管理部门或授权代表                                                                              | 出资人或出资人代表                                                                 |
| 投资方式    | 直接投资、注入资本金                                                                               | 直接投资、合作（合伙）投资等                                                            |
| 决策内容和程序 | 项目建议书 (或初步可研)→批复立项→可行性研究报告→审批决策                                                          | 以可研为主；必要预可研，**可用产业发展规划代替预可研 / 项目建议书**<br>核准项目：编制项目申请书；<br>申请财政资金：编制资金申请报告 |
| 投资范围    | 公共领域、以非经营性为主；原则上不直接投资经营性项目。<br>确需支持经营性项目：资本金注入、投资补助、贷款贴息                                 | 经营性项目为主；含特许经营（PPP）                                                        |
| 管理模式    | **审批制**。直接投资 / 资本金注入：审批项目建议书、可研、初步设计；履行咨询评估、专家论证、公众参与、风险评估；代建、稽查、审计、竣工验收、后评价、责任追究、事中事后监管 | 企业自主决策；**备案为主，少数核准**；外商投资执行负面清单制度                                         |

### （四）项目决策应遵循的原则

1. 科学决策：方法科学，依据充分，数据可靠  
2. 民主决策：核心是**借用外脑**，如咨询机构、专家、公众参与 。//区分：科学侧重方法 / 数据；民主侧重多方外部力量参与。

3. **效益（效果）最大化原则**

- ✅企业投资项目：遵循市场规律，**经济效益、环境效益、社会效益三者统一**。
- ✅政府非经营性项目：优先**社会效益、生态环境效益**，满足公共利益、社会需求。

4. **风险责任原则**

- 总方针：**谁投资、谁决策、谁收益、谁承担风险**
- 政府投资：健全政府投资**责任追究制度**。
- 企业投资：企业自主决策，自担风险。
- 委托咨询机构：决策者委托咨询，咨询机构承担**咨询责任**。

5. **可持续发展原则**：审批、核准、备案的重要条件；落实行业准入、负面清单、严守生态红线，把控项目合规性。

## 四、项目决策责任

### （一）政府投资主管部门

依据 <u>《国务院关于投资体制改革的决定》（国发〔2004〕20 号）</u>

建立新型投资体制：市场引导投资、企业自主决策、银行独立审贷、融资方式多样、中介服务规范、宏观调控有效。

- 对项目审批（核准）以及向国务院提出审批（核准）的审查意见承担责任。
- 国家和地方搭建项目在线监管平台，强化事中、事后监管，严格责任追究。

### （二）项目（法人）单位

- 申报程序合规、申报材料真实、按审批 / 核准 / 备案的建设内容实施建设。
- 承担项目**市场前景、技术方案、资金来源、经济效益**等全部投资风险。
- **谁投资、谁决策、谁收益、谁承担风险**，企业依法自主决策。

### （三）咨询机构

1.质量责任

- 咨询单位：对咨询质量负总责
- 主持人员：负主要直接责任
- 参与人员：对本人编写篇章负责
- 制度：咨询成果质量终身负责制、质量追溯机制

2.咨询单位违规及处罚（发展改革部门管）

处罚：责令改正；情节严重→警告、移出备案名录、取消资信评价等级；触犯法律追究法律责任

- 备案信息弄虚作假
- 违背独立公正，协助骗取批文、国家资金
- 弄虚作假、泄露商业秘密、不正当竞争
- 咨询成果严重质量问题
- 未建立完整咨询成果档案
- 伪造、涂改、出租、出借、转让资信证书
- 提供虚假材料申请资信评价
- 协助他人虚假办理咨询工程师登记

 3.咨询工程师个人违规及处罚

处罚：警告、通报批评、**注销登记证书、收回执业专用章**；触犯法律追究法律责任

- 执业登记弄虚作假
- 准许他人以本人名义执业
- 涂改、转让登记证书、执业专用章
- 接受影响公正执业的酬劳

### （四）金融机构

独立审贷，对贷款风险负责。

## 五、项目决策中涉及到的支撑性文件

## 六、项目监管

### （一）中央预算内投资项目  
日常监管责任单位现场核查监督，执行**三到现场**：开工到现场、建设到现场、竣工验收到现场。

各级发改部门监督检查要点：  
①项目申请材料真实准确完整，项目符合支持方向；  
②按要求开工，建设进度符合规定；  
③通过全国投资项目在线审批监管平台（国家重大建设项目库）及时完整填报项目信息；  
④中央预算内投资足额及时到位，无闲置、转移、侵占、挪用；  
⑤总投资无大幅缩减，不突破核定投资概算；  
⑥按规定履行竣工验收程序；  
⑦法律法规规定的其他内容。

### （二）企业投资项目

依据：<u>《企业投资项目事中事后监管办法》（2023 年修订）</u>

- 核准项目：由**核准机关**监管
- 备案项目：由**备案机关**监管
- 核查是否完成核准 / 备案手续：项目所在地**县级以上发改部门**实施监管

核准项目监管内容：  
①通过在线平台如实及时报送开工、建设进度、竣工等实施信息；  
②建设地点、规模、内容发生较大变更，按规定办理变更手续；  
③需延期开工的，按规定办理延期开工手续；   
④按照核准的建设地点、建设规模、建设内容开展建设。

# 第二节 项目决策分析与评价的任务和基本要求
## 一、项目决策分析与评价的任务★★

贯穿全过程：规划研究→可行性研究→项目后评价；由浅入深、由粗到细，满足决策要求，可供回顾。

主要任务：

1. 分析建设可能性；核查与各级规划、产业政策、企业发展战略的符合性；研究项目建设运营必备条件。
2. 分析建设必要性，推荐满足市场需求的产品（服务）方案、建设规模。
3. 比选推荐先进、可靠、适用、合理的建设方案。
4. 估算投资与费用；计算分析盈利能力、偿债能力、财务生存能力。
5. 从经济、社会、资源、环境、安全卫生角度评价外部影响；评价经济合理性、社会协调性、资源节约综合利用水平。
6. 识别项目风险，提出风险防范、降低风险的措施。
7. 综合研判项目目标实现程度，判别建设必要性、技术经济可行性，给出研究结论。
8. 针对建设运营相关问题，提出对策建议。
9. 开展项目后评价：对决策、实施、运营全面对比评价，总结经验教训、提出改进建议；后评价结果为本项目运营及后续项目决策提供借鉴。
10. 开展其他专项研究与评价。

⚠️提示：任务覆盖前期可研阶段，也包含**后评价**环节，不局限于项目投资决策之前。

## 二、项目决策分析与评价的基本要求★

（一）坚持推动高质量发展  
（二）资料数据准确可靠  
（三）方法科学

三类方法：🔴考点

1. **经验判断法**
多用于难以定量化的抽象因素（社会、心理、道德因素等）。  
缺点：易受个人主观认识限制；需要配合其他方法互补验证。
2. **数学分析法**
包含系统分析、线性分析、统筹方法等定量手段；结论严密、准确。
3. **试验法**  

（四）定量分析与定性分析相结合，**以定量分析为主**  
（五）动态分析与静态分析相结合，**以动态分析为主**  
（六）多方案比选与优化（灵魂）

## 三、投资项目决策程序★★★

### （一）我国投资项目决策程序关键改革点
（无考点）

### （二）审批制项目决策程序

适用：中央政府**直接投资、资本金注入**的政府投资项目。  
使用其他政府资金项目，除履行本程序外，还需编制**资金申请报告**。  
政府投资项目审批文件：**项目建议书、可行性研究报告、初步设计**（三件套）。

**1.项目建议书（初步可行性研究报告）**

项目单位依据规划报送，报审批部门审批。

- 中央预算内投资**3000 万元及以上**、跨地区 / 跨部门 / 跨领域统筹项目：国家发改委审批，或委托中央部门审批；特别重大项目发改委核报国务院批准。
- 其余项目：中央有关部门审批，抄送国家发改委。

**2.项目可行性研究报告**

项目建议书获批后，项目单位编制可研报告，内容深度需符合规定。

**3.初步设计**

已批复可研报告作为项目建设依据。  
项目单位凭批复办理规划许可、正式用地手续；委托有资质单位开展初步设计，报批**初步设计及概算**。

4.“放管服” 改革简化审批

依据：<u>《国家发展改革委关于进一步推进投资项目审批制度改革的若干意见》</u>

- 已列入发展规划、专项规划、区域规划的政府投资项目：**可不再审批项目建议书**。
- 改扩建、建设内容单一、投资规模小、技术方案简单项目：可合并编制、审批项目建议书、可研报告、初步设计（三合一）。

### （三）核准制项目的核准程序

实行核准制的企业投资项目，仅向政府提交**项目申请书（报告）**。

政府核准审查角度：维护经济安全、合理开发利用资源、保护生态环境、优化重大布局、保障公共利益、防止出现垄断。

- 国家发改委、国务院行业管理部门核准的地方企业项目：由项目所在地省级发改、行业主管部门出具初审意见后上报。
- 需国务院核准的项目：国家发改委审核后报国务院核准。

结果文书：

- 予以核准：出具核准文件；
- 不予核准：书面通知企业并说明理由；
- 国务院核准项目：由国务院投资主管部门出具核准 / 不予核准书面通知。

### （四）备案制项目的备案程序

依据：<u>《中共中央、国务院关于深化投融资体制改革的意见》(2016)</u>

**《核准目录》以外**的企业投资项目，一律备案制；企业自主决策，遵循属地原则。

**开工建设前**，通过在线平台报送信息：

1. 企业基本情况
2. 项目名称、建设地点、建设规模、建设内容
3. 项目总投资额
4. 项目符合产业政策的声明

企业对备案信息真实性负责；**备案机关不得设置前置条件**。  
企业凭《项目备案通知书》、项目备案代码，办理规划、土地、施工、环保、消防、设备进口、减免税确认等后续手续。

### （五）政府和社会资本合作（PPP）项目决策程序
🔵 了解，PPP过时
- 地方政府可授权行业主管部门、事业单位作为**项目实施机构**；
- 职责：编制特许经营方案、选择特许经营者、签订特许经营协议、项目实施监管、合作期满移交接收。
- 地方发改部门：综合协调，把关特许经营方案，依法履行项目审批、核准或备案职责。

项目分类办理程序：

- 政府以**资本金注入**支持的特许经营项目：按《政府投资条例》履行**审批**手续。
- 社会资本单独投资项目：按《企业投资项目核准和备案管理条例》履行**核准或备案**手续。

### （六）资金申请报告的申报与审批

适用依据：<u>《中央预算内投资补助和贴息项目管理办法》《国家高技术产业发展项目管理暂行办法》《国际金融组织和外国政府贷款投资项目管理暂行办法》</u>

适用上述范围内企业投资项目，需单独报送**资金申请报告**审批。

1.**投资补助和贴息项目**

申请单位依据申报公告、通知编制资金申请报告，明确补助贴息目的、预定目标、实施时间、支持范围、资金安排方式、工作程序、时限要求。

2.**国际金融组织和外国政府贷款项目**

- 借用国外贷款项目必须纳入**国外贷款备选项目规划**。（一阶段）
- 申报备选项目材料：
  ①项目简要情况
  ②项目建设必要性
  ③拟申请贷款类别或国别
  ④贷款金额及用途
  ⑤贷款偿还责任
- 已纳入规划的项目，按项目属性分别履行审批、核准或备案手续。（二阶段）

| 项目类别             | 管理方式            | 审批 / 核准备案要求                                         |
| ---------------- | --------------- | --------------------------------------------------- |
| 中央统借统还项目         | 按中央政府直接投资项目管理   | 项目建议书、可研由国家发改委审批，或审核后报国务院审批                         |
| 省级政府偿还或提供还款担保项目  | 按省级政府直接投资项目管理   | 审批权限执行国务院、国家发改委相关规定                                 |
| 用款单位自行偿还、无政府担保项目 | 参照《政府核准的投资项目目录》 | 目录内核准；目录外备案；<font color="#ff0000">无需编制资金申请报告</font> |

国家发改委受理资金申请报告，审批条件：（三阶段）

1. 符合国家利用国外贷款的政策及使用规定
2. 已纳入国外贷款备选项目规划
3. 项目已履行审批、核准或备案手续
4. 贷款偿还、担保责任明确，还款资金来源与还款计划落实
5. 国外贷款机构已对项目贷款初步承诺

国务院及国家发展改革委对项目可行性研究报告或资金申请报告的**批准文件**，是对外谈判、签约和对内办理转贷生效、外债登记、招标采购和免税手续的依据。

### （七）企业自主决策的投资项目

分类：国内企业境内投资项目、国内企业境外投资项目、外商投资项目（中外合资、合作、外商独资）

1.**国内企业境内投资项目**

除《核准目录》规定的核准类项目外，一律备案制；投资决策由企业自主负责。

2.**外商投资项目**

- 审核维度：除经济安全、资源、生态环境、产业布局、公共利益、防止垄断之外，增加**市场准入、资本项目管理**审核。
- 执行依据：<u>《外商投资准入负面清单》</u>、<u>自贸区负面清单</u>，由发改委、商务部适时更新公布。
- 规则
  ①禁止类领域：境外投资者不得投资；
  ②限制类领域：需办理外资准入许可，即核准；
  ③有股权要求领域：不得设立外商投资合伙企业。

依据<u>《外商投资项目核准和备案管理办法》</u>

**（1）外商投资核准项目**

- 国家发改委核准：有中方控股（含相对控股）要求、总投资（含增资）**限额及以上鼓励类**；总投资（含增资）**限额及以上限制类（不含房地产）**。
- 省级政府核准：限制类房地产项目；总投资（含增资）**限额以下其他限制类项目**。
- 地方政府核准：负面清单内有中方控股要求、总投资（含增资）**限额以下鼓励类项目**。

 **（2）外商投资备案项目**

不在《核准目录》、外商负面清单核准范围内的外商投资项目，由地方投资主管部门备案。

3.**境外投资项目**

- 管理模式：按鼓励、限制、禁止分类管理。
- 境外投资项目定义：投资主体以<font color="#ff0000">新建、并购、参股、增资、注资、融资担保</font>等方式，取得境外所有权、经营管理权及相关权益的项目。

（1） 核准管理

仅针对**敏感类项目**，核准机关：**国家发展改革委**。

（2） 备案管理

通过网络系统报送项目备案表及附件

- 中央管理企业：由集团 / 总公司提交；
- 地方企业：企业直接提交。

备案审核要点：是否属于备案范围；符合法律法规、产业及境外投资政策；符合资本项目管理规定；不危害国家主权、安全、公共利益；投资主体具备相应投资实力。

# 第三节 项目前期咨询成果
## 一、工程咨询基本概念

### （一）工程咨询的含义

- 工程咨询单位：中国境内设立，从事工程咨询业务，具备**独立法人资格**的企业、事业单位。
- 全过程工程咨询：覆盖项目**前期研究决策‑实施‑运营**全生命周期，提供含规划设计在内的组织、管理、经济、技术多维度咨询服务；可采用多种组织模式，提供局部或者整体解决方案。

### （二）工程咨询的原则

1. **独立性**：不受委托方及其他方面干扰，对咨询成果质量负责，承担相应责任。
2. **科学性**：依据、方法、过程科学；实事求是、尊重客观规律，成果经得起实践检验。
3. **公正性**：坚守立场，尊重委托方同时兼顾各方利益，恪守职业道德，协调处理分歧。
4. **合规性**：依法办事，遵守国家、行业、地方及委托方的法律法规、标准规范。
## 二、工程咨询的业务范围

依据：<u>发改委2017年第 9 号令《工程咨询行业管理办法》</u>

1.**规划咨询**  
总体规划、专项规划、区域规划、行业规划。

2.**项目咨询★**  
投资机会研究、投融资策划；项目建议书（预可研）、可行性研究报告、项目申请书、资金申请报告；PPP 项目咨询。

3.**评估咨询★**  
受政府及部门委托：对规划、项目建议书、可研、项目申请书、资金申请报告、PPP 实施方案、初步设计评估；规划与项目中期评价、后评价；项目概预决算审查；其他投资管理相关专业技术服务。

4.**全过程工程咨询**  
多服务方式组合，面向项目决策、实施、运营阶段，提供局部或整体解决方案、管理服务。

## 四、项目前期咨询成果间的相互关系★★★★★
🔴考点
### （一）项目规划与机会研究和项目建议书的关系

- 可用**项目规划代替机会研究、商业计划书**，用作招商引资材料
- 企业投资项目：可用项目规划替代项目建议书
- 政府投资项目：项目规划不能替代项目建议书（预可研），严格执行审批流程

### （二）项目建议书（初步可行性研究）与可行性研究的关系

1. 项目建议书 vs 初步可行性研究报告

- 初步可行性研究报告：内容更详尽，包含完整研究过程；
- 项目建议书：内容简略，报批时重点展示预可研的**结论**；详略程度可根据投资主体、审批机构要求调整。

2. 预可研 vs 可行性研究  
内容框架大体相近，可研是预可研的**延伸和深化**；但二者在目的作用、论证重点、研究方法、深度、基础数据上存在明显区别。

### （三）项目申请书（报告）与可行性研究报告的关系

核准类企业投资项目，可在可研报告基础上补充内容，编制项目申请书；**可研是编制项目申请书的基础**。

## 六、项目前期咨询成果的质量保证

### （一）项目经理责任制

保证项目前期咨询成果质量的基础。

### （二）成果质量评审制

1.**内部评审**

①项目团队组织评审：项目经理组织项目组员自我评审，自查修正；项目经理为基层质量负责人。

2.**外部评审**

①项目业主组织的评审  
②委托第三方外审

### （三）成果质量评价标准

前期咨询成果难以全部定量衡量，4 项评价维度：

1. 与国家法律法规、政策的符合性
2. 与国民经济和社会发展目标的一致性
3. 委托方的满意度
4. 各方利益权衡的协调性

### （四）咨询机构的选择
依据<u>《工程咨询单位资信评价标准》</u>

- 评价核心指标：**近 3 年专业技术力量、合同业绩、守法信用记录**
- 评定规则：每年集中申请评定；取得资信满**3 年重新评定**；期间动态调整。
