**本章考情**

篇幅最小，较为简单，没有过多理解性内容，以硬知识点为主。  
本章预计 <font color="#ff0000">6 分</font>，一般是 2 单 2 多。

学好本章，最主要是理清<font color="#ff0000">"财政补贴类"、"高技术产业化项目类"、"国际金融组织贷款类"</font>三类资金申请报告的内容以及区别，特别容易考区分。

# 第一节 概述

## 一、资金申请报告的定义和作用

**定义**：资金申请报告是企业为获得<font color="#ff0000">政府资金支持、财政专项资金支持、国际金融组织或者外国政府贷款</font>而编制的向有关政府提交的文件。

- 政府资金支持：<font color="#ff0000">政府投资补助、奖励、转贷和贷款贴息</font>等方式，一般是**中央预算内投资**这类通用性政府投资资金。
- 财政专项资金支持：中央政府有关部门和地方政府各有关部门根据经济发展和政策导向等，阶段性提出支持产业发展方向或专项支持资金，如信息安全专项资金、科技重大专项及产业化基金、先进制造业智能化改造基金、农业专项补助资金等。
- 国际金融组织或外国政府贷款：主要指使用世界银行、亚洲开发银行、国际农业发展基金会等国际金融组织贷款和外国政府贷款，及与贷款混合使用的赠款、联合融资等，这些资金均由<font color="#ff0000">政府转贷</font>（<font color="#ff0000">给了要还，但比商业贷款利率低</font>）。

✅ 分级管理：

- 政府资金支持和专项资金支持可分为<font color="#ff0000">国家级</font>和<font color="#ff0000">地方级</font>两个级别；
- 国家级资金支持一般对资金申请报告的内容和深度有明确规定和要求；
- 地方级资金支持应执行地方政府有关规定，无规定者可参照国家规定执行或者适当简化

**作用**：根据政府投资导向的要求，从资金使用的合理性角度，申报单位向政府回答企业拟建项目的<font color="#ff0000">合规性、企业承担项目的能力、项目财务上的可行性</font>以及拟建项目对经济、社会、资源、环境等方面的影响和贡献，具有较强的<font color="#ff0000">政策性、时效性和技术性</font>。

⚠️ 对比第四章项目申请书：项目申请书回答"外部性、公共性"，为核准提供依据；  
资金申请报告回答"合规性、承担能力、财务可行性"及经济社会资源环境影响，突出政策性、时效性、技术性。

## 二、资金申请报告的分类

根据<font color="#ff0000">资金来源和性质</font>不同，现阶段有明确规定和要求的资金申请报告主要有三类：

1. <font color="#ff0000">财政补贴性资金支持项目</font>资金申请报告
2. <font color="#ff0000">高技术产业化项目</font>资金申请报告（产学研一体化项目）
3. <font color="#ff0000">国际金融组织贷款项目</font>资金申请报告

### （一）财政补贴性资金支持项目资金申请报告

#### 1.适用范围

依据：<u>《中央预算内投资补助和贴息项目管理暂行办法》（2025年12月29日国家发展改革委令第38号）</u>。

- 以<font color="#ff0000">投资补助和贴息</font>方式使用中央预算内资金（包括长期建设国债投资），应编制资金申请报告（重点）；
- 按照规定需要各级政府财政补贴、转贷、贷款贴息或资金支持的项目，应编制资金申请报告。

#### 2.资金申请报告应具备的内容（5 项）

1. 项目单位的基本情况和财务状况；
2. 项目的基本情况；
3. 申请投资补助或贴息资金的<font color="#ff0000">主要原因和政策依据</font>；
4. 项目招标内容（适用于申请投资补助或贴息资金<font color="#ff0000">500 万元及以上</font>的投资项目）；
5. 国家发展改革委要求提供的其他内容。

#### 3.报送时应附送的文件（8 项）

| 序号 | 附件内容 | 备注 |
| :-: | --- | --- |
| ① | 政府投资项目的可行性研究报告批准文件 | —— |
| ② | 企业投资项目的核准文件或备案证明 | —— |
| ③ | 规划部门出具的规划选址意见 | —— |
| ④ | 自然资源部门出具的项目用地预审意见 | —— |
| ⑤ | 环保部门出具的环境影响评价文件的审批意见 | —— |
| ⑥ | 申请贴息的项目须出具项目单位与有关金融机构签订的<font color="#ff0000">贷款协议</font> | 仅贴息项目 |
| ⑦ | 项目单位对资金申请报告内容和附属文件<font color="#ff0000">真实性负责的声明</font> | —— |
| ⑧ | 国家发展改革委要求提供的其他文件 | 兜底条款 |

📌 **附件简化条件**：凡已经由<font color="#ff0000">国务院、国家发展改革委、省级和计划单列市发展改革委审批或核准的投资项目</font>，或者申请使用资金额在<font color="#ff0000">200 万元以下</font>的投资项目，可适当简化附件。

### （二）高技术产业化项目资金申请报告

#### 1.适用范围

依据：<u>《国家高技术产业发展项目管理暂行办法》</u>。

- 国家高技术产业化项目、国家重大技术装备研制和重大产业技术开发项目、国家产业技术创新能力建设项目、国家高技术产业技术升级和结构调整项目和其他国家高技术产业发展项目；
- 申请使用<font color="#ff0000">国家或地方政府投资资金补助</font>时，应编制资金申请报告。

#### 2.资金申请报告应具备的内容（5 项）

1. 项目单位的基本情况和财务状况；
2. 项目的基本情况：包括项目背景、项目建设（研发）内容、总投资及资金来源、技术工艺、各项建设（研发）条件落实情况等；
3. 申请国家补贴资金的主要理由和政策依据；
4. 项目招标内容（适用于申请国家补贴资金<font color="#ff0000">500 万元及以上</font>的投资项目）；
5. 国家发展改革委项目公告或通知要求提供的其他内容。

#### 3.报送时可附送的文件（8 项）

| 序号  | 附件内容                                           | 备注                  |
| :-: | ---------------------------------------------- | ------------------- |
|  ①  | 政府投资项目的可行性研究报告批准文件，或企业投资项目的核准文件或备案证明           |                     |
|  ②  | <font color="#ff0000">技术来源及技术先进性的有关证明文件</font> | 📌 高技术产业化项目**独特附件** |
|  ③  | 规划部门出具的规划选址意见                                  | ——                  |
|  ④  | 自然资源部门出具的项目用地预审意见                              | ——                  |
|  ⑤  | 环保部门出具的环境影响评价文件的审批意见                           | ——                  |
|  ⑥  | 金融机构出具的贷款承诺；申请贴息的项目还须出具项目单位与有关金融机构签订的贷款协议或合同   | ——                  |
|  ⑦  | 项目单位对项目资金申请报告内容和附属文件真实性负责的声明                   | ——                  |
|  ⑧  | 国家发展改革委项目公告或通知要求提供的其他文件                        | 兜底条款                |

⚠️ 对比：高技术产业化项目是"可"根据情况附送（非必须）；财政补贴性项目是"应"附送。

### （三）国际金融组织贷款项目资金申请报告

#### 1.适用范围

依据：<u>《国际金融组织和外国政府贷款投资项目管理暂行办法》</u>。

- 借用世界银行、亚洲开发银行、国际农业发展基金会等国际金融组织贷款和外国政府贷款，及与贷款混合使用的赠款、联合融资等投资项目；
- 项目纳入<font color="#ff0000">国外贷款备选项目规划</font>并完成<font color="#ff0000">审批、核准或备案</font>手续后，项目用款单位须按要求向有关部门报送项目资金申请报告；
- 由<font color="#ff0000">国务院及国务院发展改革部门审批</font>的项目可行性研究报告，可研中应当包括项目资金申请报告内容，<font color="#ff0000">不再单独审批</font>项目资金申请报告。

#### 2.资金申请报告应具备的内容（7 项）

1. **项目概况**：项目建设规模及内容、总投资、资本金、国外贷款及其他资金、项目业主、项目执行机构、项目建设期；
2. **国外贷款来源及条件**：国外贷款机构或贷款国别、还款期、宽限期、利率、承诺费等；
3. **项目对外工作进展情况**；
4. **贷款使用范围**：贷款用于土建、设备、材料、咨询和培训等的资金安排；
5. **设备和材料采购清单及采购方式**：主要设备和材料规格、数量、单价；
6. **经济分析和财务评价结论**；
7. **贷款偿还及担保责任、还款资金来源及还款计划**。

#### 3.报送时应附送的文件（4 项）

1. 项目批准文件（项目可行性研究报告批准文件、项目申请书（报告）核准文件或项目备案证明）；
2. 国际金融组织贷款项目，应提供<font color="#ff0000">国外贷款机构对项目的评估报告</font>；
3. 国务院行业主管部门提出项目资金申请报告时，如项目需地方政府安排配套资金、承担贷款偿还责任或提供贷款担保的，应出具<font color="#ff0000">省级发展改革部门及有关部门意见</font>；
4. 申请使用<font color="#ff0000">限制性采购</font>的国外贷款项目，应出具对国外贷款条件、国内外采购比例、设备价格等<font color="#ff0000">比选结果报告</font>。

## 三、资金申请报告的编制依据

- 通常以<font color="#ff0000">资金提供者提出的要求</font>为依据；
- 资金提供者的要求一般体现在管理办法中，如《中央预算内投资补助和贴息项目管理暂行办法》《国家高技术产业发展项目管理暂行办法》《国际金融组织和外国政府贷款投资项目管理暂行办法》等。

## 四、资金申请报告的编制要求

- 可以<font color="#ff0000">自行编制</font>或选择有能力、有实力的咨询机构进行编制；
- 咨询机构应当做到依法、独立、客观、公正，对其编制文件的<font color="#ff0000">准确性</font>负责；
- 编制要求（两点）：
  1. 首先要根据所申请资金的<font color="#ff0000">来源和性质</font>，充分响应资金使用要求，反映投资主管部门对投资行为的<font color="#ff0000">引导和约束</font>；
  2. 其次要根据<font color="#ff0000">资金使用时限</font>，反映项目投资主体情况、项目情况和资金使用情况。

# 第二节 资金申请报告的编制

## 一、资金申请报告的编制内容

资金申请报告编制内容共 7 大块：（一）项目单位及拟建项目情况；（二）项目的基本内容；（三）项目融资分析；（四）项目建设前期准备基本情况；（五）项目财务、经济和清偿能力分析；（六）社会影响分析；（七）项目风险及防范分析。

### （一）项目单位及拟建项目情况（抄可研）

目的：简述项目申报单位、项目主要投资者和项目的基本情况，为项目资金审查机关分析判断项目申报单位是否具备承担拟建项目的资格、是否符合资金发放条件等提供背景和依据。

#### 1.项目申报单位基本情况

- 一般企业：名称、性质、法人、注册地点、注册资本、主营业务、营业期限、企业投资人（或者股东）构成、主要投资项目、现有生产能力、项目申报单位及主要投资人近几年财务状况（近三年经审计的<font color="#ff0000">资产负债表、利润表和现金流量表</font>）以及信用情况等。
- 技术改造项目（改建、扩建和技术改造项目）：要说明现有企业基本情况，包括企业生产、营销、员工、财务等状况、环保现状、安全生产、政府有关部门态度以及企业目前存在的主要经营发展问题等。
- 购并项目：说明拟购并的目标企业情况，介绍购并的各参与方。
- 利用国际金融组织和外国政府贷款投资项目：说明项目业主、项目执行机构情况；说明企业是否使用过该项资金，简述项目的基本情况；说明具体使用情况和资金偿还情况。
- 利用国债（贴息）或各种财政资金的项目：说明企业是否使用过该项资金，简述利用该项资金项目的执行情况、完成情况和效果。未完成或改变用途的，需要做必要的说明。

⚠️ 易混点（考区分）：股份制企业 → 介绍<font color="#ff0000">主要投资人情况</font>；技术改造项目 → 说明现有企业基本情况；购并项目 → 说明拟购并目标企业、各参与方；国债（贴息）项目 → 说明该项资金项目执行情况、完成情况和效果。

#### 2.拟建项目概况

包括拟建项目的建设地点、项目的背景及意义、拟实现的目标等。

（1）**项目名称、建设地点、项目性质及类型，经营机制及管理体制**

- 改建、扩建和技术改造项目要说明拟建项目与现有企业的关系和依托情况；
- 购并项目，简述购并的方式，介绍目标企业的生产、经营等情况。

（2）**项目提出的背景，投资的必要性和意义**

- 从市场需求与竞争、原材料供应与配套、资源的节约与合理配置、技术进步与先进性、建设条件与优势、企业发展与效益、投资效果与公众利益、规划布局与产业政策的符合性、土地利用与环境改善等方面分析项目建设的必要性和意义，说明项目建设方案设计的合理性。

（3）**项目的目标**

|  目标  | 内容                                                                                       |
| :--: | ---------------------------------------------------------------------------------------- |
| 市场目标 | 拟建项目产品的国内外市场状况（竞争程度、供应现状、需求现状）、市场前景、目标市场和市场份额、对市场的满足程度；产品市场竞争力，项目产品是否构成垄断                |
| 技术目标 | 采用的工艺技术、原料路线所达到的水平；技术水平在国内外的地位；自动控制达到的水平；主要设备选择所达到的水平；引进设备、材料列出明细，说明是否符合国家相关政策           |
| 经济效果 | 项目投资估算值；融资设想与方案，资金来源（权益资金和债务资金）；主要财务指标（项目财务内部收益率或经济内部收益率、净现值等）；享受的国家或地方优惠政策              |
| 社会效果 | 对地方经济的贡献和影响（税收、劳动力就业、相关产业带动）；对行业乃至国民经济的贡献（技术进步、竞争力提升、增加供应、产品质量提高、相关行业带动）；对环境和生态以及文化遗产的影响 |
| 其他效果 | 根据项目具体情况和需要列出，如环境目标、安全目标、质量目标等                                                           |

### （二）项目的基本内容

包括建设（开发）规模与产品（服务）方案、工程技术方案和主要技术来源、主要设备选型和采购方案、系统配套公用或辅助工程、投资规模和资金筹措方案等。

#### 1.建设规模

- 简述拟建项目的建设规模和产品方案；
- 说明项目建设规模是否符合<font color="#ff0000">经济规模或达到规模经济</font>；是否符合<font color="#ff0000">资源的优化配置</font>；项目规模与产品是否构成<font color="#ff0000">垄断和形成过度竞争</font>；
- 对于多装置、多产品的项目，要说明项目分装置的建设规模、产品方案和商品量。

#### 2.工艺技术

1. 简要叙述拟建项目采用的技术、原料路线选择及其主要优缺点；
2. 简述项目的自动控制方案与自控水平的选择；
3. 简述主要设备的选择，列出主要设备一览表；对于引进设备、材料要按照规格、型号、材质等列出清单和单价，以备享受<font color="#ff0000">免征或减征关税优惠政策</font>时有关机构审查使用；
4. 改建、扩建和技术改造项目要说明拟采用技术装备与原有生产工艺技术的关系，说明原有设施的可利用情况；
5. 购并项目，要简述目标企业的技术装备状况和水平；需要改造的，要说明拟采用的技术装备与原有生产工艺技术的关系，说明原有设施的可利用情况。

#### 3.工程方案

1. **总图运输方案**：简述总图布置的原则和方案，给出总平面布置图；简述运输、装卸方案和运输措施；简述原材料和产品的储存方案；
2. **土建方案**：根据项目特点和地方有关规定，确定土建设计原则与方案；
3. **供水方案**：根据项目用水特点，确定各种用水的供水方案，说明节水方案和提高水的重复利用率方案，提出有关节水措施；
4. **排水方案**：根据项目排水特点和环保要求，给出各种废水排水量及组成，确定废水排水方案及处理方案；
5. **供电及电信方案**：简述供电及变配电方案，简述电信方案；
6. **供热方案**：简述供热方案，给出热平衡图；
7. **其他辅助生产和公用工程方案**：供气（空气、氮气、氧气、惰性气体等）方案；机修、电修、仪修、仓储等设施配置原则与方案；
8. 改建、扩建和技术改造项目要说明<font color="#ff0000">增量以及与原有设施的关系</font>，依托现有设施或以新带老的要作说明；
9. 在开发区或园区建设的项目，应根据开发区、园区条件和要求构建工程方案；
10. 列出执行的相关标准、规范。

#### 4.配套措施

1. **厂外运输配套与设施**：依托社会力量的要作社会运输能力说明；修建码头、车站、专用线的要做方案说明；
2. **厂外供电线路及设施**：供电外线和变配电情况以及供电方案、供电电源和设施的保证供应程度；
3. **厂外供水情况**：供水水源、水资源情况以及供水方案，说明水源和水的保证供应程度；
4. **厂外排水情况**：项目排水方案和接纳水体情况；有集中水处理设施的，说明集中处理设施的能力和接收条件；
5. **渣场（填埋场）情况**：选择基本情况及工程方案；需要征地的要有土地部门意见；需要单独环保批准的，要有环保部门意见；说明废渣（固体废物）综合利用情况；有放射性废渣时，需要单独处理方案；
6. **区域其他配套设施与能力**。

#### 5.项目组织

1. **项目建设管理与组织**：说明项目的建设管理模式，投资者自行管理的需简要说明组织方式；
2. **项目计划进度**：描述项目建设计划进度和投产时间；简述项目实际计划执行情况，根据项目实际进展预测计划的变化情况；
3. **项目定员与员工培训**：简述项目人员招聘计划与培训情况；
4. **项目的招投标情况**：应严格按照《必须招标的工程项目规定》和《中华人民共和国招标投标法》等有关的法律法规开展招标工作；根据项目性质，按照有关规定编制项目招标内容。

#### 6.投资估算

- 简要叙述投资估算依据和说明，估算项目总投资，包括<font color="#ff0000">建设投资、建设期利息、流动资金</font>，列出投资估算表；
- 利用<font color="#ff0000">国际金融组织或政府贷款</font>的投资项目：应说明投资的方向和该部分资金的使用范围，一般来说，该部分资金<font color="#ff0000">只能用于购置必要的生产设备</font>，且需要列出购置设备清单和价格表；
- 利用<font color="#ff0000">国债（贴息）或政府各种财政资金</font>的项目：应说明投资的支持方向和投资的范围，一般政府补贴资金仅用于<font color="#ff0000">生产装置、必要的辅助生产和公用工程</font>等。

### （三）项目融资分析

通过项目的融资分析，说明项目<font color="#ff0000">融资构成、融资成本</font>，分析项目融资方案合理性，说明<font color="#ff0000">政府资金介入的必要性</font>，说明拟申请资金数额和理由。

#### 1.项目融资构成与资金来源

- 简要说明项目需要筹措的项目总投资（建设投资、建设期利息、流动资金）；
- 资本金出资方案：说明权益资金来源与构成，说明各出资方的出资能力，附开户银行出具的资金信用证明等。

#### 2.拟申请资金数额和理由

- 提出拟申请资金数额；
- 综合拟建项目政策符合性、技术水平、资金筹措方案等，说明政府资金或者国外组织贷款介入的必要性。

#### 3.项目资金使用计划分析

- 说明包括借贷资金、权益资金、拟借入的政府资金或国际金融机构或政府贷款资金的<font color="#ff0000">逐年用款计划</font>；
- 说明资金的使用范围，包括用于土建、设备、材料、咨询和培训等方面的资金安排。

#### 4.简要进行融资成本和融资方案合理性分析

- 分析项目融资成本，说明融资方案的合理性和合法性。

### （四）项目建设前期准备基本情况

#### 1.项目进展情况

1. 简述项目投资的规划、可研、核准、备案等政府审批情况，项目建设的各项前期和开工准备情况；
2. 介绍利用外资项目的对外工作情况；
3. 对于已经开工建设的项目或在建工程：说明工程进展情况，介绍已完成的工程量和投资比例，提供<font color="#ff0000">形象进度图片、设备购置合同、施工合同</font>及有关资料等。

#### 2.项目的市场与竞争力研究情况

1. 项目的市场情况简介；
2. 项目的竞争力状况简介；
3. 项目所处行业的竞争态势简介。

#### 3.项目主要政策性内容落实情况

1. 项目的清洁生产和环保情况简介，环评内容的落实和有关批复情况；
2. 项目在安全、卫生、消防等方面的措施简介，有关部门的意见或态度；
3. 项目在土地利用和规划方面的介绍，有关土地管理部门和规划部门的意见。

### （五）项目财务、经济和清偿能力分析

通过拟建项目的财务分析和经济分析，说明拟建项目在预测期内、预测条件下的财务效益情况和经济效益情况，反映项目的经济运行能力。

#### 1.项目财务分析

简要说明拟建项目采取的财务分析依据和基础条件，分析项目的<font color="#ff0000">成本费用、销售收入、税收、优惠政策、财务指标</font>等。

#### 2.项目经济分析

简要说明拟建项目的经济分析依据、基础条件和经济指标，通过分析说明拟建项目在预测期内、预测条件下的经济效益情况，反映项目经济运行能力。

#### 3.项目清偿能力分析

- 简要分析项目的<font color="#ff0000">还款期、利息备付率、偿债备付率</font>等指标，说明项目是否具有清偿能力；
- 简要分析项目的贷款偿还计划、担保责任、还款资金来源，说明项目的财务可持续性；
- 简要分析项目投资者（企业）近三年的资产负债、利润、现金流量、投资者（非政府投资者）清偿能力、银行信誉等级等，说明投资者的财务状况和资产实力；
- 利用国外贷款的项目，还应根据贷款机构的要求，编制相应的偿还计划等。

### （六）社会影响分析（<font color="#00b0f0">和第四章的内容完全一样</font>）

通过拟建项目的社会影响分析，说明项目将引起的社会影响效果、项目的社会适应性，可能引发的社会风险和采取的对策。

### （七）项目风险及防范分析

通过项目风险及防范措施分析，对项目可能面临的<font color="#ff0000">风险因素、风险发生的可能性、风险影响程度</font>进行说明，并提出风险防范和降低风险的对策。包括：

1. <font color="#ff0000">资源风险</font>和防范措施；
2. <font color="#ff0000">市场风险</font>和防范措施；
3. <font color="#ff0000">技术装备风险</font>和防范措施；
4. <font color="#ff0000">投资与融资的风险</font>和防范措施；
5. <font color="#ff0000">其他风险</font>和防范措施。

⚠️ 易混点：社会稳定风险分析属于"社会影响分析"的内容，不属于"项目风险及防范分析"。

## 二、资金申请报告相应附件

### （一）附表

根据需要，出具必要的附表，如：<font color="#ff0000">投资估算表、财务分析附表、引进设备一览表</font>等。

### （二）附件

根据需要，出具必要的附件、附文等，如：

- 已经通过核准的项目，可以附项目申请书（报告）或有关政府部门的核准意见；
- 增资、购并项目的公司董事会决议；
- 高新技术产业化项目，出具有关<font color="#ff0000">技术鉴定证明和专利证明</font>等。

# 第三节 资金申请报告的评估要点

## 一、中央预算内投资补助和贴息项目

对企业申请中央预算内<font color="#ff0000">投资补助、转贷和贴息</font>项目的资金申请报告进行咨询评估，主要评估要点（5 项）：

1. 是否符合<font color="#ff0000">中央预算内投资的使用方向</font>；
2. 是否符合<font color="#ff0000">有关工作方案</font>的要求；
3. 是否符合投资补助、转贷和贴息资金的<font color="#ff0000">安排原则</font>；
4. 提交的相关文件是否<font color="#ff0000">齐全、有效</font>；
5. 项目的主要<font color="#ff0000">建设条件是否基本落实</font>。

📌 此类项目带有很强的<font color="#ff0000">政策性和政府导向色彩</font>，不同的时期、不同的资金类型，政府会有不同的评估要求，应根据具体情况和要求调整评估内容和重点。

## 二、国外贷款投资项目

对企业申请借用国际金融组织和外国政府贷款投资项目的资金申请报告进行咨询评估，主要评估要点（5 项）：

1. 是否符合国家<font color="#ff0000">利用国外贷款的政策及使用规定</font>；
2. 是否符合<font color="#ff0000">国外贷款备选项目规划</font>；
3. 是否已按规定履行<font color="#ff0000">审批、核准或备案</font>手续；
4. 国外贷款<font color="#ff0000">偿还和担保责任是否明确</font>，还款资金来源及还款计划是否落实；
5. 国外贷款机构对项目贷款是否已<font color="#ff0000">初步承诺</font>。

📌 不同的国际金融组织和外国政府贷款在资金使用和要求上都有所区别，评估时应根据具体情况结合资金来源和要求调整评估内容和重点。
